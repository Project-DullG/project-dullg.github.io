〈미식의 대가〉

점수를 정리한 뒤 최종 지목 결과와 같은 엔딩을 선택한다.

1. 점수 계산개인 목표 점수 확인 기준 보기

캐릭터 시트의 목적과 최종 투표 결과를 대조해 각자의 점수를 먼저 합산한다.

왕실 요리장을 살해한 범인은 다니엘이다.

다니엘을 지목한 플레이어는 자신의 범인 지목 관련 목표를 확인한다. 캔디가 다니엘을 지목했다면 범인 지목 목표 +5점을 얻는다.

지목 회피 점수

다니엘·애쉬·류진환은 자신을 지목하지 않은 플레이어마다 +3점을 얻는다. 캔디가 최다 지목을 받지 않았다면 +1점을 얻는다.

비밀 유지 점수

다니엘은 자신이 조살과를 사용했다고 직접 인정하지 않았다면 +3점을 얻는다. 애쉬는 자신이 조살과를 사용했다고 직접 인정하지 않았다면 +2점을 얻는다. 류진환은 자신이 까마귀 소속이라고 직접 인정하지 않았다면 +2점을 얻는다. 캔디는 아버지와 있었던 일을 직접 인정하지 않았다면 +3점, 왕실 요리장이 아버지라는 사실을 직접 인정하지 않았다면 +2점을 얻는다. 다른 플레이어가 비밀을 밝혔더라도 본인이 인정하지 않았다면 점수를 얻는다. 엔딩에서 공개되는 사실은 이미 계산한 점수를 바꾸지 않는다.
2. 최종 지목 가장 많은 표를 받은 인물

동률이면 해당 인물들을 다시 지목한다. 다시 동률이 나오면 아래 ‘재지목도 동률인 경우’를 선택한다.

ENDING A

❯ ENDING B

❯ ENDING C

❯ ENDING D

❯ ENDING F
